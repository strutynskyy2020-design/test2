# Встановлення VPDK Bonus v124

Для повного виправлення потрібно оновити і Netlify, і Google Apps Script.

## 1. Оновлення Netlify

1. Розпакуйте архів `vpdk-bonus-v124-all-operators-reports-fix.zip`.
2. Завантажте весь проєкт у репозиторій, з якого Netlify виконує deploy, або запустіть звичний ручний deploy.
3. Дочекайтеся статусу `Published`.

Це оновлює Netlify Function, сторінки застосунку та версію PWA-кешу.

## 2. Оновлення Google Apps Script

1. Відкрийте Apps Script, підключений до Google Таблиці `Goals`.
2. Відкрийте основний файл коду.
3. Повністю замініть його вміст кодом із `VPDK-Code-v124.gs`.
4. Збережіть проєкт.
5. Якщо вебзастосунок Apps Script використовує версійний deployment, створіть нову версію deployment і залиште ті самі права доступу.
6. Запустіть функцію `refreshReports` вручну.
7. Надайте дозволи, якщо Google попросить повторну авторизацію.

Після виконання `refreshReports` на прихованому аркуші `_TM6_REPORT_CACHE` має бути сформований snapshot версії:

`v124-all-operators-auto-goals`

## 3. Очищення старої PWA-версії

Після публікації:

1. Повністю закрийте вкладку або встановлений PWA.
2. Відкрийте застосунок знову.
3. Якщо старий екран залишився, зробіть жорстке оновлення сторінки: `Ctrl + Shift + R`.
4. У крайньому разі очистьте дані сайту для домену Netlify та увійдіть повторно.

## Очікуваний результат

- `kubraky` та інші нові оператори TM7/TM10 бачать власні звіти.
- Відсутність ручного рядка на аркуші `Goals` більше не приховує всі показники.
- На головній відображаються фактичні кредитний, дебетовий і депозитний результати.
- На `/goals` відкривається звичайна сторінка цілей, а не повідомлення «Цілі ще не додано».
- Коли для оператора буде додано справжній рядок `Goals`, застосунок використає його замість автоматичних цілей.
