# VPDK BONUS V117 — Адмін-керування Банкою Команди

## Додано
- Нова вкладка в адмін-панелі: **Банка Команди**.
- Адміністратор бачить окрему картку для кожної команди.
- Для кожної банки показуються:
  - поточний цикл;
  - зібрані Point;
  - залишок до 15 000 Point;
  - відсоток прогресу;
  - кількість учасників, які зробили внесок;
  - статус досягнення цілі.
- Кнопка **Скинути ціль банки**.

## Як працює скидання
1. Поточний цикл закривається та зберігається в історії.
2. Прогрес нової банки стає `0 / 15 000 Point`.
3. Список внесків нового циклу починається з нуля.
4. Старі внески не видаляються з історії.
5. Point не повертаються на особисті баланси.
6. Команда отримує сповіщення про початок нового збору.

## Деплой
1. Розгорніть backend із цього архіву.
2. Розгорніть frontend і Netlify Functions.
3. Google Apps Script змінювати не потрібно.
4. Після deployment повністю закрийте PWA та відкрийте її знову.

Міграція MongoDB вручну не потрібна: нові колекції та індекси створюються автоматично під час запуску backend.
