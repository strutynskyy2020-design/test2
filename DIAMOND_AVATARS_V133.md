# Алмазні аватарки v133

## Архітектура

Збережено чинний принцип застосунку:

- `avatar_url` містить портрет;
- `avatar_rarity` містить рівень `diamond`;
- `AvatarFrame` накладає рамку окремим шаром;
- чоловіча та жіноча алмазні рамки вибираються за кодом у URL портрета;
- окремо вибрати рамку оператор не може.

## Тимчасова видача

Backend зберігає попередній стан аватара в `diamond_avatar_restore`, встановлює алмазний стан на 72 години, а після завершення відновлює:

- `avatar_url`;
- `active_avatar_prize_id`;
- `avatar_rarity`;
- `avatar_daily_bonus`;
- `avatar_task_replacements`.

Повторна видача алмазної аватарки під час активного періоду не затирає початковий стан для відновлення.

## Адмінські маршрути

- `POST /api/admin/users/{user_id}/diamond-avatar`
- `DELETE /api/admin/users/{user_id}/diamond-avatar`

Тіло POST:

```json
{
  "avatar_code": "male-diamond-1"
}
```

Допустимі коди:

- `male-diamond-1`;
- `female-diamond-1`;
- `female-diamond-2`;
- `female-diamond-3`.

## Постійний виклик

У нижній частині сторінки `Завдання дня` додано незмінний щоденний блок:

> Зроби 10 видач кредитних продуктів за день і отримай алмазну аватарку.

Блок показує всі чотири портрети вже разом із відповідною рамкою та пояснює бонуси. Сам аватар видається адміністратором після перевірки результату.
