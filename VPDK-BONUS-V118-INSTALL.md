# VPDK Bonus V118 — депозитні звіти

## Що додано

- Депозитний рейтинг команд і операторів.
- Періоди **Місяць** та **Вчора**.
- Персональна сторінка депозитних показників.
- Метрики:
  - оброблено;
  - призначено зустрічей від оброблених;
  - видано від оброблених;
  - кількість видач;
  - проекційний результат.
- Розподіл видач за напрямками:
  - INB;
  - VSE;
  - WEB;
  - WEB APPS;
  - загальний підсумок.
- Командне фільтрування за тими самими правилами, що й у кредитних та дебетових звітах.
- Адміністратор може переглядати всі дозволені команди.
- Депозитні підсумки додаються до аналітики керівника.

## Очікувана структура Google Таблиці

Назва аркуша має бути точно:

```text
Deposit
```

Apps Script шукає чотири блоки:

```text
Dep month
Dep yesterday
Giving month
Giving yesterday
```

У блоках `Dep month` і `Dep yesterday` підтримуються рядки:

```text
Обработано (#)
Назначено встреч от обработанных (%)
Выдано от обработанных (встреча) (%)
выдачі
Projective_rate
```

Командні підсумкові колонки можуть називатися:

```text
TM_1 Підсумок
TM_6 Підсумок
TM_7 Підсумок
```

У блоках `Giving month` і `Giving yesterday` потрібні заголовки:

```text
team | Агент | Inb | Vse | Web | Web_apps | Загальний підсумок
```

## Установлення

1. Розгорніть backend з архіву V118.
2. Розгорніть frontend і Netlify Functions з архіву V118.
3. У Google Apps Script замініть код файлом `integrations/google-sheets/Code-v118.gs`.
4. Відкрийте:

```text
Deploy → Manage deployments → Edit → New version → Deploy
```

5. Для кнопки **«Оновити звіти»** залиште функцію:

```text
refreshReports
```

6. Натисніть **«Оновити звіти»** один раз.
7. Повністю закрийте PWA та відкрийте її знову.

## Нові маршрути

```text
/goals/deposit
/goals/deposit/me
```

## Важливо

Після зміни даних на вкладці `Deposit` вони потрапляють у застосунок лише після натискання **«Оновити звіти»**.
