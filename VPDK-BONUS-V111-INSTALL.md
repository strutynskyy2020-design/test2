# VPDK Bonus v111

## Що змінено

- Усі видимі назви застосунку змінено на **VPDK Bonus**.
- **TM6 Sudoku** перейменовано на **VPDK Sudoku**.
- Оновлено назву PWA, заголовок браузера, опис, іконки та splash-екрани.
- Темна тема стала основною для нових і наявних установок після першого запуску v111.
- Світла тема залишається доступною через кнопку перемикання теми на головній сторінці, екранах входу та реєстрації.
- Картка Sudoku і вся гра отримали окрему світлу палітру без темної золотої підкладки.
- Зменшено адаптивний розмір бренду та назви Sudoku, додано захист від накладання тексту на кнопки на вузьких екранах.
- Дані користувачів, прогрес і Google-кеш не скидаються: старі внутрішні ключі збережені для сумісності.

> Назви реальних команд на кшталт **TM6**, **TM7** не перейменовувалися. Це дані команд, а не назва застосунку.

## Встановлення

1. Розгорніть frontend і Netlify Functions із цього архіву.
2. Розгорніть backend із цього ж архіву, щоб нові назви використовувалися в нагородах, системних записах та API.
3. Для зміни заголовків повідомлень Google Sheets замініть Apps Script на `integrations/google-sheets/Code-v111.gs` і створіть нову версію Web App.
4. Функція кнопки в таблиці залишається без змін:

```text
refreshReports
```

5. Натискати «Оновити звіти» лише через ребрендинг не потрібно.
6. Повністю закрийте PWA та відкрийте знову. Для гарантованої зміни назви та іконки на домашньому екрані видаліть стару PWA й установіть її повторно, оскільки iOS/Android іноді кешують ярлик окремо від Service Worker.

## Перевірки

- Python та JSON синтаксис.
- Синтаксичний розбір 109 JS/JSX-файлів.
- Apps Script `Code-v111.gs`.
- 8 тестів Bonus Match і Sudoku.
- Логіка командних Google-звітів і рейтингів.
- Маніфест, Service Worker v111, нові PWA-іконки та splash-екрани.
