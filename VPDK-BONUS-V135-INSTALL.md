# Встановлення VPDK Bonus v135

## Що оновити

Потрібно розгорнути:

1. frontend / Netlify;
2. backend.

Google Apps Script не змінюється. Залишається поточна робоча версія `VPDK-Code-v130.gs`.

## Після деплою

1. Виконайте `Ctrl + Shift + R` у браузері.
2. Для встановленої PWA повністю закрийте застосунок і відкрийте його повторно.
3. Перевірте жіночу алмазну аватарку у квестах, профілі та рейтингах.
4. Перевірте чоловічу алмазну аватарку, вона повинна зберегти темну крижану рамку.

Service Worker оновлено до `vpdk-v135`, а жіноча рамка отримала нову адресу `diamond-female-floral-v135.webp`, тому старий файл не повинен залишитися в кеші.
