# VPDK Bonus v113: встановлення

## Що входить у v113

- повний аудит світлої теми для всіх сторінок застосунку;
- контрастніші підписи, статуси, іконки, поля, картки та кнопки;
- окрема вкладка адміністратора **«Бали та баланс»**;
- нарахування, списання та встановлення точного балансу користувача;
- магазин без вкладок **«Сертифікати»** і **«Мерч»**;
- аватари прибрані з вкладки **«Все»** та залишені лише у **«Аватарках»**;
- компактні горизонтальні ряди аватарів за рідкістю;
- Service Worker оновлено до `vpdk-v113`.

## Оновлення

1. Розгорніть папку `backend` на сервері backend.
2. Розгорніть `frontend` та `netlify/functions` на Netlify.
3. Google Apps Script змінювати не потрібно. Залишається поточна версія.
4. Після deployment повністю закрийте встановлену PWA та відкрийте її повторно.
5. Якщо залишився старий інтерфейс, очистьте дані сайту або перевстановіть PWA, щоб система забрала Service Worker `vpdk-v113`.

## Коригування балансу

В адмін-панелі відкрийте **«Бали та баланс»**, виберіть користувача та одну з дій:

- **Нарахувати**: додає Point і зберігає попередню логіку XP;
- **Списати**: зменшує поточний баланс;
- **Встановити точний баланс**: замінює баланс на вказане число без додавання XP.

Баланс не може стати від’ємним. Кожна фактична зміна записується в історію транзакцій разом із попереднім і новим балансом.

## Магазин

У користувацькому магазині доступні лише:

- **Все**: загальні призи без аватарів;
- **Привілеї**;
- **Аватарки**.

Сертифікати та мерч не видаляються з бази даних і залишаються доступними адміністратору для історії або майбутнього використання, але не показуються користувачам у магазині.

## Перевірки

- Python backend компілюється без синтаксичних помилок.
- Перевірено синтаксис 108 JS/JSX-файлів.
- Внутрішній валідатор v113 пройдено.
- 8 тестів Bonus Match і Sudoku пройдено.
- Контраст основних світлих текстових токенів перевірено за порогом WCAG 4.5:1 на білому тлі.

Повну production-збірку React у цьому середовищі не виконано, оскільки в архіві немає `node_modules`, а доступний внутрішній npm registry не містить усіх залежностей проєкту.
