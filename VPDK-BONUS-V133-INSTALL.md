# VPDK Bonus v133 — алмазні аватарки

Версія зібрана поверх v132. Код скасованої v127 не використовується.

## Що оновити

1. Розгорнути backend з папки `backend`.
2. Розгорнути frontend та Netlify Functions з папки `frontend`.
3. Google Apps Script не змінювати. Залишається `VPDK-Code-v130.gs`.
4. Після деплою виконати `Ctrl + Shift + R` або повністю перезапустити PWA.

## Як видати алмазний аватар

1. Відкрити адмін-панель.
2. Перейти у вкладку `Юзери`.
3. Відкрити редагування потрібного оператора.
4. У блоці `Алмазний аватар` обрати один із чотирьох варіантів.
5. Натиснути `Видати на 3 дні`.

Після трьох днів система автоматично повертає попередній аватар і його бонуси. Перевірка завершення виконується під час запитів користувача та фоновим очищенням backend кожні 5 хвилин.

## Алмазні переваги

- `+100 Point` один раз на кожен київський календарний день;
- `+5` додаткових замін завдань;
- тривалість `3 дні`;
- видати, змінити або забрати аватар може лише адміністратор.

## Рамки

Аватар і рамка залишаються двома окремими шарами:

- чоловічий `male-diamond-1` використовує `/avatar-frames/diamond-male.png`;
- три жіночі аватарки використовують `/avatar-frames/diamond-female.webp`;
- у профілі зберігається `avatar_rarity: "diamond"`;
- компонент `AvatarFrame` автоматично визначає потрібну алмазну рамку за `avatar_url`.
