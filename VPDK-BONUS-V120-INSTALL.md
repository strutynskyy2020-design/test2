# VPDK Bonus v120 — Банка Команди + депозитний проекційний рейтинг

## Що виправлено

### Банка Команди
Причиною помилки завантаження був конфлікт MongoDB під час автоматичного створення банки: однакові поля записувалися одночасно через `$setOnInsert` і `$set`.

У v120:
- створення Банки Команди працює без конфлікту;
- додана кнопка **«Повторити»**;
- frontend показує реальний текст помилки backend замість загального повідомлення.

### Депозитний напрямок
Першою сторінкою депозитного напрямку тепер є **проекційний рейтинг операторів** із блоку `Deposit` на вкладці **Аркуш2**.

Порядок розділу:
1. Проекційний рейтинг операторів своєї команди.
2. Кнопка **«Переглянути мої показники»**.
3. Кнопка **«Рейтинг по видачах»**.

Окремий рейтинг видач зберіг періоди **Місяць / Вчора** та дані INB, VSE, WEB, WEB APPS.

## Деплой

1. Розгорніть **backend** з архіву v120.
2. Розгорніть **frontend і Netlify Functions**.
3. У Google Apps Script замініть код файлом `VPDK-Code-v120.gs`.
4. Створіть нову версію Web App:
   `Deploy → Manage deployments → Edit → New version → Deploy`.
5. Для кнопки залиште функцію:

```text
refreshReports
```

6. Натисніть **«Оновити звіти»** один раз.
7. У Netlify бажано виконати **Clear cache and deploy site**.
8. Повністю закрийте PWA на телефоні та відкрийте повторно.

## Формат проекційного рейтингу на Аркуш2

Код шукає блок із заголовком `Deposit`:
- перша колонка блоку: команда (`TM_1`, `TM_6`, `TM_7` тощо);
- друга колонка: логін оператора;
- третя колонка: проекційний результат у відсотках.

Рядок із назвою команди та порожнім логіном використовується як загальний результат команди.
