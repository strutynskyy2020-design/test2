# VPDK Bonus v145 — встановлення

## Що оновити

Потрібно розгорнути:

1. **backend** з пакета v145;
2. **frontend / Netlify** з пакета v145.

Google Apps Script змінювати не потрібно.

## Нова вкладка адміністратора

У панелі адміністратора з’явилася вкладка **«Щедрий куб»**. У ній можна:

- змінити вартість кожного повторного кидка;
- змінити мінімальний і максимальний виграш для граней 1–6.

Перший кидок кожного працівника за київську добу залишається безкоштовним.

## Збереження налаштувань

Налаштування зберігаються у MongoDB в колекції `app_settings` з ідентифікатором `generous_cube`. Окрема міграція не потрібна. До першого збереження використовуються базові значення v144/v139.

## Після деплою

Зробити hard refresh або повністю перезапустити PWA. Service Worker оновлено до `vpdk-v145`.
