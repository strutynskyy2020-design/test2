# Bonus Match beige code theme v91

Implemented directly in the React/Tailwind code:

- Bonus Match route shell uses a warm light beige palette based on `#F5F5DC`.
- Header and bottom navigation switch to the light theme only on `/games/bonus-match`.
- Game controls and information panels use warm off-white/beige surfaces with muted brown-gray text.
- The lavender game board and its cells retain their current colors.
- Faux decorative frames/gloss overlays on normal pieces and obstacles are disabled so artwork sits directly on the board cells.
- Other application routes retain the existing dark theme.

Files changed:

- `frontend/src/components/AppLayout.jsx`
- `frontend/src/pages/BonusMatch.jsx`
- `frontend/src/index.css`
