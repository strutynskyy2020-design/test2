# VPDK Bonus v146 — відсотки випадіння граней Щедрого куба

## Що додано

У вкладці адміністратора **«Щедрий куб»** тепер можна редагувати не лише вартість повторного кидка та нагороди, а й шанс випадіння кожної грані.

Для граней 1–6 доступне поле **«Ймовірність випадіння»** з точністю до 0,01%.

Стандартні значення:

| Грань | Ймовірність |
|---:|---:|
| 1 | 37% |
| 2 | 28% |
| 3 | 20% |
| 4 | 10% |
| 5 | 4% |
| 6 | 1% |

## Правила збереження

- кожна ймовірність може бути від 0% до 100%;
- повинні бути присутні всі шість граней;
- сума значень після округлення до 0,01% повинна дорівнювати **100%**;
- грань зі значенням 0% не випадає;
- кнопка **«Стандартні відсотки»** повертає набір 37 / 28 / 20 / 10 / 4 / 1.

Адмін-панель показує поточну суму. Якщо вона відрізняється від 100%, налаштування не зберігаються.

## Backend

У документі `app_settings` з `id: generous_cube` зберігається нове поле:

```json
"probabilities": [
  { "face": 1, "probability_percent": 37.0 },
  { "face": 2, "probability_percent": 28.0 },
  { "face": 3, "probability_percent": 20.0 },
  { "face": 4, "probability_percent": 10.0 },
  { "face": 5, "probability_percent": 4.0 },
  { "face": 6, "probability_percent": 1.0 }
]
```

Кожен кидок формує вагову таблицю з актуальних налаштувань адміністратора. У записі історії кидка додатково фіксується ймовірність грані, яка діяла на момент кидка.

## Сумісність

Якщо база ще не містить `probabilities`, автоматично використовуються стандартні значення. Старий frontend v145 також може тимчасово працювати з backend v146: якщо поле не передане, поточні ймовірності зберігаються без змін.
