# VPDK BONUS V116 — Банка Команди

## Що додано
- У розділі **Магазин** додана нова вкладка **"Банка Команди"**.
- Для **кожної команди** створюється **окрема банка**.
- Користувач бачить **тільки банку своєї команди**.
- Нова ціль банки: **15 000 Point**.
- Нагорода: **Групова зустріч на 30 хв**.
- Додані внески 50 / 100 / 250 / 500 Point.
- Внески зменшують баланс користувача, але **не зменшують рейтинг**, так само як і покупки в магазині.
- Доданий список внесків команди та персональний показник "Ваш внесок".

## Що змінено на бекенді
- Додані API:
  - `GET /api/team-bank`
  - `POST /api/team-bank/contribute`
- Додані колекції / індекси:
  - `team_banks`
  - `team_bank_contributions`
- Додані внутрішні сповіщення для поповнення банки та досягнення цілі.

## Деплой
1. Замініть проект на цей V116.
2. Перезапустіть backend.
3. Перезберіть / передеплойте frontend.
4. Відкрийте застосунок і перевірте вкладку **Магазин → Банка Команди**.

## Примітка
Міграція вручну не потрібна — банки створюються автоматично при першому відкритті або внеску команди.
