# TM6 Bonus v109 — net Point leaderboards

## Що виправлено

### Особистий рейтинг

Рейтинг більше не підсумовує лише позитивні нарахування.

Для періодів **День / Тиждень / Місяць** результат обчислюється так:

```text
усі нарахування Point − усі витрати Point
```

Тому покупки призів, платні кидки куба, життя та бустери Bonus Match, а також від'ємні коригування адміністратора знижують результат за відповідний період.

Для **Всього** використовується фактичний поточний баланс користувача. Це гарантує, що рейтинг показує Point, які реально залишилися після всіх витрат.

### Рейтинг команд

На сторінці команд додано періоди:

- День
- Тиждень
- Місяць
- Всього

Командний результат є сумою чистих результатів усіх поточних учасників команди. Середній показник також розраховується з чистого результату.

## Сумісність API

`GET /api/leaderboard/teams` зберігає старі поля `total_earned` і `avg_earned`, але починаючи з v109 вони містять чистий результат. Також додано зрозумілі поля `score`, `avg_score` і `period`.
