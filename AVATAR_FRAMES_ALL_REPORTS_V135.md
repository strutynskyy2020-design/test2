# VPDK Bonus v135: рамки аватарів у всіх звітах

## Виправлена причина жіночої рамки

Попередня перевірка використовувала `includes("male-diamond-")`. Назва `female-diamond-1.webp` теж містить фрагмент `male-diamond-`, тому жіночі алмазні аватарки помилково отримували чоловічу рамку.

У v135 перевіряється лише початок назви файлу:

```js
const filename = source.split("/").pop() || "";
return filename.startsWith("male-diamond-") ? "male" : "female";
```

Результат:

- `male-diamond-1.webp` → `diamond-male.png`;
- `female-diamond-1.webp` → `diamond-female-floral-v135.webp`;
- `female-diamond-2.webp` → `diamond-female-floral-v135.webp`;
- `female-diamond-3.webp` → `diamond-female-floral-v135.webp`.

## Двошарова логіка не змінена

- `avatar_url` зберігає портрет;
- `avatar_rarity` зберігає рідкісність;
- `AvatarFrame` окремо накладає рамку;
- алмазна рамка визначається за назвою алмазного портрета.

## Рамки у звітах

Компонент `AvatarFrame` тепер використовується у:

- кредитному рейтингу;
- дебетовому рейтингу;
- особистому звіті дебетових видач;
- депозитному проекційному рейтингу;
- рейтингу депозитних видач;
- рейтингу ПУМБ Online;
- рейтингу активації карток;
- адмін-звіті завдань дня;
- адмін-звіті цілей.

Глобальний LeaderBoard, стрічка, головна сторінка, магазин і Bonus Match уже використовували `AvatarFrame` раніше.

## Backend

До відповідей адмін-звітів додано `avatar_rarity`, щоб інтерфейс завжди отримував одночасно портрет і тип рамки.
