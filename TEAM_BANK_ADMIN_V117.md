# V117 — Адмін-керування Банкою Команди

## Backend

Додані endpoint-и:
- `GET /api/admin/team-banks`
- `POST /api/admin/team-banks/{team_id}/reset`

Для кожної банки використовується номер циклу `cycle_number`.
Після скидання:
- попередній цикл архівується в `team_bank_cycles`;
- банк отримує новий номер циклу;
- `current_points` скидається до нуля;
- `unlocked_at` очищується;
- нові внески належать тільки новому циклу.

## Frontend

В адмін-панелі додана вкладка **Банка Команди** з:
- прогресом усіх команд;
- статусом досягнення цілі;
- кількістю учасників;
- підтвердженням перед скиданням;
- поясненням, що Point не повертаються користувачам.
