# VPDK Bonus V171 — пакет для Netlify

Це повний актуальний код застосунку без локальних секретів, кешів, журналів роботи, `node_modules`, Python `.venv` та завантажених користувачами файлів.

## Netlify

Конфігурація вже знаходиться у `netlify.toml`:

- base: `frontend`
- build command: `npm run build`
- publish: `frontend/build`
- functions: `netlify/functions`

Перед production-збіркою в Netlify потрібно залишити налаштованими змінні середовища сайту. Мінімально потрібна:

```text
REACT_APP_BACKEND_URL=https://адреса-вашого-backend-без-/api
```

Для Netlify Functions також використовується `BACKEND_API_URL`. Решта ключів інтеграцій і токенів мають зберігатися тільки в Environment variables Netlify та середовищі backend — не у файлах репозиторію.

Backend FastAPI та MongoDB не запускаються цією статичною конфігурацією Netlify. Папка `backend` включена в архів як повний актуальний серверний код і має бути оновлена у вашому чинному backend-середовищі.

- персональний кіт для кожного працівника замість AI-тренажера;
- сувора Tamagotchi-механіка потреб, хвороб, втечі та смерті;
- кімната з незалежними WebP-шарами, екіпіруванням, зняттям і переміщенням предметів;
- три різні серверно-перевірені мініігри;
- особистий сюжет «Нічна пошта» з трьома напрямами характеру та фіналами;
- дев’ять випадкових подій із реальними перевагами, витратами й тимчасовими станами;
- вплив виборів на довіру, потреби, риси, улюблену їжу, іграшки, матеріали та поведінку;
- щоденник, експедиції, тренування, проєкти, подарунки й колекційні предмети;
- захист від повторного нарахування нагород і застарілих сюжетних запитів;
- оптимізовані PWA-асети без зберігання зображень у MongoDB.

Перевірено перед пакуванням: 72 backend-тести, 22 frontend-тести та production build.
