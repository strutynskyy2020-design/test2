# VPDK Bonus v143 — Diamond spacing polish

## Зміни

Після виправлення масштабування рамки у v142 додано окрему внутрішню безпечну зону для двох найщільніших поверхонь:

- картки профілю на головній сторінці;
- карток стрічки активності.

## Картка профілю

- збільшено внутрішні відступи тільки для користувача з алмазною аватаркою;
- кнопку перемикання теми відсунуто від правого верхнього кристала;
- аватар, ім'я, рівень і XP більше не притискаються до декоративної рамки;
- додано адаптивні значення для екранів до 380 px.

## Стрічка активності

- текст, бейджі, реакції та коментарі отримали додатковий простір усередині алмазної рамки;
- анімоване сяйво розширено, щоб воно не концентрувалося під текстом;
- звичайні події без алмазної аватарки не змінені.

## Технічна реалізація

Додано контекстні класи:

- `diamond-profile-card`
- `diamond-profile-theme-toggle`
- `diamond-profile-avatar`
- `diamond-profile-copy`
- `diamond-profile-progress`
- `diamond-feed-shell`

Логіка `AvatarFrame`, `avatar_url`, `avatar_rarity` та 9-slice рамка v142 не змінювались.
