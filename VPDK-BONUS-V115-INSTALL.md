# VPDK Bonus v115: виправлення «Загального підсумку»

## Що виправлено

- Значення з колонки **«Загальний підсумок»** більше не видаляється командним фільтром.
- `projective_rate_overall`, `processed_tasks_overall` та інші поля `*_overall` залишаються спільними для всіх команд.
- Внутрішні колонки на кшталт `TM_6 Підсумок` більше не замінюють загальний результат на сторінці «Мої показники».
- PWA-кеш Google-звітів переведено на v115, тому старий некоректний payload не буде повторно показаний.
- Service Worker оновлено до `vpdk-v115`.

## Встановлення

1. Розгорніть frontend і Netlify Functions із цього архіву.
2. Backend та Google Apps Script змінювати не потрібно.
3. Після deployment повністю закрийте встановлену PWA та відкрийте її повторно.
4. Перше відкриття «Мої показники» після оновлення виконає одноразове свіже завантаження звіту.

Натискати «Оновити звіти» необов’язково, якщо опублікований snapshot уже містить колонку «Загальний підсумок». Якщо дані самої таблиці були змінені, натисніть кнопку як зазвичай.
