# TM6 Bonus v104: глобальний кеш Google-звітів у PWA

## Що виправлено

У v103 кожна сторінка окремо монтувала `useDailyGoogleReports()`. Через це мобільна PWA могла повторно читати browser storage, запускати перевірку версії та показувати екран «Завантаження…» при переходах між сторінками.

У v104:

- додано один `GoogleReportsProvider` над усіма маршрутами;
- сторінки лише читають уже завантажений стан із Provider;
- великі звіти зберігаються в IndexedDB;
- наявний кеш v103 автоматично переноситься з localStorage в IndexedDB;
- старий звіт залишається на екрані під час фонової перевірки;
- повний `google-goals` викликається тільки при першому запуску на пристрої, після очищення кешу або коли `snapshot_version` змінився;
- переходи між «Цілі», кредитними/дебетовими звітами, рейтингами, графіком і головною сторінкою не запускають повторне завантаження;
- Service Worker та реєстрацію PWA піднято до v104.

## Як працює кнопка в Google Таблиці

Кнопка, як і раніше, повинна бути прив'язана до функції:

```text
refreshReports
```

Після натискання Apps Script створює новий snapshot у прихованому аркуші `_TM6_REPORT_CACHE` і змінює `snapshot_version`.

PWA:

1. одразу показує останній звіт з IndexedDB;
2. у фоні перевіряє опубліковану версію;
3. якщо версія змінилася, один раз завантажує новий персональний звіт;
4. зберігає його в IndexedDB для всіх наступних переходів.

Перевірка виконується один раз при запуску PWA і не частіше одного разу на 30 хвилин після повернення застосунку на передній план. Це легка перевірка manifest. Повний персональний звіт не завантажується, якщо версія не змінилася.

## Встановлення

1. Розгорнути проєкт v104 на Netlify.
2. Замінити Google Apps Script на `integrations/google-sheets/Code-v104.gs`.
3. Створити нову версію Web App через `Deploy → Manage deployments → Edit → New version → Deploy`.
4. Переконатися, що кнопка «Оновити звіти» викликає `refreshReports`.
5. Натиснути кнопку один раз після deployment.
6. На телефоні повністю закрити встановлену PWA та відкрити її знову, щоб активувався Service Worker v104.

## Очікувана поведінка

- На новому телефоні або після виходу з акаунта перше завантаження неминуче.
- Після першого успішного завантаження переходи між сторінками працюють без повторного екрана завантаження.
- Під час публікації нового snapshot користувач бачить старі дані, доки нові тихо завантажуються у фоні.
- Після виходу з акаунта локальний кеш очищається з міркувань приватності.
