# Оптимізація ваги та трафіку — 10.09.2026

653 PNG гри «Пошук предметів» перекодовано у WebP quality 92 без зміни роздільності.
Піксельні розміри й альфа-канали перевірено для кожного файлу. Координати предметів,
складність, нагороди, ідентифікатори та всі 54 рівні залишилися попередніми.

| Показник | До | Після |
| --- | ---: | ---: |
| Перекодовані зображення | 229,59 МБ | 46,12 МБ |
| Публічні ресурси frontend | 249,00 МБ | приблизно 65,62 МБ |
| Найбільше оптимізоване зображення | | 0,86 МБ |

МБ тут = 1 000 000 байтів. Це розміри файлів, а не вимір місячного рахунку.
Передача тих самих перекодованих зображень потребує приблизно на 80% менше байтів.
Витрати на функції, backend, базу даних та production-деплої залежать від їхнього використання.

## Кешування

- Нові URL містять SHA-256 хеш вмісту; змінена картинка отримує нову адресу.
- Netlify віддає `/hidden-objects/optimized/*` з `max-age=31536000, immutable`.
- Service Worker v177 зберігає ці зображення між оновленнями застосунку.
- Кеш зображень обмежено 48 МіБ та 256 файлами. Окремий файл — до 2 МіБ.
- JS/CSS з хешем у назві повторно використовуються з кешу. HTML і service worker перевіряють оновлення.
- Production source maps вимкнено в `netlify.toml`, щоб вони не збільшували публічну збірку.
- API та Netlify Functions продовжують запитувати актуальні дані через мережу.
- Встановлення PWA завантажує лише оболонку та іконки. Головна сторінка більше
  не завантажує наперед графіку й код Bonus Match та Hidden Objects.
- Помилки квоти кешу не перетворюють успішно завантажене зображення на порожній екран.

## Сумісність та розгортання

`frontend/public/_redirects` містить 653 точні rewrites зі старих PNG-адрес на нові WebP.
Вони стоять перед SPA fallback. Завдяки цьому старий backend продовжує віддавати робочі
адреси картинок після оновлення лише Netlify. Версії v1–v3 також мають легкі сумісні файли.
Важкі PNG-оригінали виключено з публічної папки та нового ZIP.

Для прямих нових URL оновіть також `backend/hidden_object_levels.json` у вашому backend
та перезапустіть його. Версія каталогу залишається v6, оскільки ігровий вміст не змінено.

При перенесенні пакету в існуючий Git-репозиторій **замініть папку
`frontend/public/hidden-objects` вмістом із нового архіву повністю**, щоб старі PNG
не залишилися поряд із WebP. Візьміть також нові `_headers`, `_redirects`, service worker,
код frontend та каталог backend із цього пакету. Чинні змінні середовища збережіть.

Архів містить вихідний код для Netlify Git/CLI, як попередній повний пакет.
Локальний build використовується для перевірки компіляції і не включається до ZIP.

## Перевірка і повторне використання

```text
node --test tests/service_worker_cache.test.cjs
python -m pytest tests/test_hidden_objects_v157.py tests/test_hidden_objects_mistake_limits.py tests/test_hidden_objects_v5_progress_migration.py tests/test_hidden_object_asset_budget.py -q
npm --prefix frontend run build
```

Для першої конвертації використано `backend/scripts/optimize_hidden_object_assets.py`
і Pillow. Pillow потрібен лише цьому офлайн-інструменту, а не серверу застосунку.
`frontend/asset-optimization-manifest.json` містить адреси, хеші, розміри й статистику
для перевірки кожного перетвореного файлу.

Локальні PNG-оригінали збережені окремо в
`artifacts/hidden-object-assets-before-optimization.zip`; цей резервний архів
не включено до Netlify-пакету.
