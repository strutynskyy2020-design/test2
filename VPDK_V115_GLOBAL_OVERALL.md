# Технічна зміна v115

Apps Script уже повертав загальний результат у звичайних полях `*_overall`. Помилка була в Netlify Function `google-goals`: функція `applyTeamOverall()` або замінювала ці поля значеннями з `team_overall[teamKey]`, або повністю видаляла їх, якщо командної колонки не було.

У v115 `team_overall` розглядається лише як внутрішня метаінформація парсера. Перед відповіддю клієнту вона видаляється, але всі звичайні поля `*_overall` зберігаються без змін.

Очікувана логіка:

- особистий показник: колонка оператора;
- порівняльний показник: колонка «Загальний підсумок» відповідного блоку;
- команда користувача не впливає на загальний підсумок.
