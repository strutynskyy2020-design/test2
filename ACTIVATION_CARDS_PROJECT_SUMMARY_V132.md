# VPDK Bonus v132 — «Активація карток»: підсумок проєкту

Дата: 04.08.2026  
База: v131, що продовжує робочу гілку v126. Код скасованої v127 не використано.

## Проблема

У картках персональних показників звіту **«Активація карток»** нижній рядок показував значення колонки `TM_7 Підсумок` і називався **«Команда»**.

Для порівняння оператора потрібні значення останньої колонки таблиці **«Загальний підсумок»**, тобто підсумок усього проєкту.

## Виправлення

У п'яти картках трансформації:

- `Оброблено`;
- `Середній час AHT`;
- `Згоди до оброблених`;
- `Активації від згод`;
- `Активації до оброблених`;

нижній рядок тепер:

- має назву **«Проект»**;
- спочатку читає персонально прив'язане поле `*_overall`, яке Apps Script формує з колонки **«Загальний підсумок»**;
- використовує `activation_cards_transformation_group_summaries[period].general` як резервне джерело для адміністративного перегляду;
- не використовує `*_team`, `team_summary` або підсумок TM7 для цих п'яти карток.

## Що залишено без змін

- у верхньому проекційному блоці показник **«Команда»** залишається командним;
- підпис під кількістю видач у верхньому блоці залишається командним;
- сегменти видач `A / B / C / D` і підсумок видач залишаються командними;
- особисті значення оператора не змінено;
- Google Apps Script v130 уже передає потрібні поля `*_overall`, тому його оновлювати не потрібно;
- backend не змінено.

## Контрольні значення місячного «Загального підсумку» зі скріншота

- Оброблено: `43 329`;
- AHT: `00:01:41`;
- Згоди до оброблених: `78,00%`;
- Активації від згод: `36,80%`;
- Активації до оброблених: `28,70%`.
