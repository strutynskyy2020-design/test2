# VPDK Bonus v137 — прямокутна алмазна рамка працівника

## Що додано

Коли в працівника активна аватарка з `avatar_rarity: "diamond"`, у всіх основних місцях із його аватаром тепер оформлюється не лише круглий портрет, а й уся картка працівника.

Нову прямокутну рамку показано в:

- загальному LeaderBoard;
- кредитному, дебетовому та депозитному рейтингах;
- рейтингу депозитних видач;
- рейтингах ПУМБ Online та активації карток;
- особистому звіті дебетових видач;
- стрічці активності;
- профілі на головній;
- рейтингу Bonus Match;
- картках операторів у відповідних звітах адмін-панелі.

Рамка з'являється автоматично лише тоді, коли всередині картки компонент `AvatarFrame` реально відображає рідкісність `diamond`. Для звичайних аватарів дизайн не змінюється.

## Встановлення

1. Розгорніть frontend із пакета v137 на Netlify.
2. Backend залишається версії v136, оновлювати його не потрібно.
3. Google Apps Script залишається `VPDK-Code-v130.gs`.
4. Після деплою повністю закрийте PWA та відкрийте знову або виконайте `Ctrl + Shift + R`.

Service Worker оновлено до `vpdk-v137`, а файл рамки додано до precache, тому стара версія не повинна залишитися в кеші після активації нового deployment.
