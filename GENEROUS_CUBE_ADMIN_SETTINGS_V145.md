# VPDK Bonus v145 — керування Щедрим кубом

## Реалізовано

### Адмін-панель

Додано окрему вкладку **«Щедрий куб»**:

- поле вартості повторного кидка;
- шість карток граней;
- для кожної грані окремо задаються мінімальний та максимальний виграш;
- перевірка, що мінімум не перевищує максимум;
- значення від 0 до 100 000 Point;
- відображення автора та часу останнього оновлення.

Значення `0` для вартості робить повторні кидки безкоштовними. Перший кидок і надалі безкоштовний незалежно від налаштувань.

### Backend

Додано API:

- `GET /api/admin/cube-settings`;
- `PATCH /api/admin/cube-settings`.

Параметри зберігаються в `app_settings`:

```json
{
  "id": "generous_cube",
  "paid_spin_cost": 20,
  "rewards": [
    { "face": 1, "min_reward": 1, "max_reward": 10 }
  ]
}
```

Під час кожного кидка backend повторно читає актуальні налаштування. Тому нові значення застосовуються до наступного кидка одразу після збереження.

Ймовірності випадіння граней залишаються фіксованими та не показуються працівникам.

### Екран працівника

`/games/status` тепер повертає:

- `paid_spin_cost`;
- `cube_reward_ranges`;
- актуальний `next_spin_cost`.

Сторінка Щедрого куба автоматично показує:

- нові діапазони виграшів;
- нову максимальну можливу нагороду;
- актуальну ціну кнопки кидка;
- актуальний опис унизу сторінки.
