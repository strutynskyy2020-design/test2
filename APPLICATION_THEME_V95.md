# Application Theme V95

The existing dark theme is unchanged.

The application-wide light theme now uses the approved cool off-white palette:

- page background: `#FBFBFC`
- subtle page gradient: `#FCFCFD` → `#F8F7FB`
- cards and elevated surfaces: `#FFFFFF`
- secondary surfaces: `#F7F6FA`
- borders: `#E6E3EF`
- primary text: `#252832`
- secondary text: `#70738A`
- purple accent: `#6D3DF5`

Bonus Match keeps its lavender playfield and frameless pieces/obstacles in light mode. Dark-mode selectors and colors were not changed.
