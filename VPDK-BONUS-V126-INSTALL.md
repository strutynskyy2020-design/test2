# Встановлення VPDK Bonus v126

1. Розгорніть папку `backend` з пакета v126 на backend-хостингу.
2. Перевірте, що endpoint `PATCH /api/admin/users/{id}/report-profile` доступний після деплою.
3. Розгорніть frontend та Netlify Functions із цього самого пакета.
4. Google Apps Script повторно змінювати не потрібно, якщо вже встановлено v125.
5. На пристрої оператора повністю закрийте PWA та відкрийте знову. У браузері можна виконати `Ctrl + Shift + R`.
6. В адмінці змініть тип на «Активатор». У списку користувачів одразу має з’явитися зелений напис «Активатор».
7. На акаунті оператора профіль оновиться після повернення у застосунок або максимум протягом однієї хвилини.

Якщо frontend оновлено, а backend ні, адмінка покаже точне повідомлення, що backend v126 ще не розгорнуто, замість хибного успіху.
