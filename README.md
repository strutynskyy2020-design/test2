# VPDK Bonus v125

Ця збірка додає окремі звітні профілі для продажників та активаторів усередині однієї команди.

- **Продажники** продовжують бачити кредити, дебет і депозити.
- **Активатори** бачать дві сторінки: `ПУМБ Online` та `Активація карток`.
- Звіт активації карток включає видачі за сегментами **A, B, C, D**.
- Тип звітів обирається адміністратором у профілі користувача.

Основні файли:

- `VPDK-Code-v125.gs` — Google Apps Script;
- `VPDK-BONUS-V125-INSTALL.md` — інструкція з оновлення;
- `ACTIVATION_REPORT_PROFILES_V125.md` — технічний опис;
- `test_activation_reports_v125.js` — тест парсерів Google Таблиці;
- `test_activation_profile_v125.js` — тест gateway і профільної фільтрації;
- `test_activation_frontend_v125.js` — перевірка маршрутів та інтерфейсу.
