# VPDK Bonus v150 — install

## Оновити

Потрібно оновити:

- backend;
- frontend / Netlify.

Google Apps Script змінювати не потрібно.

## Після деплою

1. Перезапустити backend, щоб створилися індекси `operator_report_daily`.
2. Задеплоїти frontend.
3. Перезапустити PWA / зробити hard refresh, щоб активувався `vpdk-v150`.
4. Відкрити кілька операторських звітів.
5. Переконатися, що в MongoDB створюється одна сутність на `user_id + date_key`.

## Поведінка

- 1 працівник = максимум 1 документ на день для всієї історії операторських графіків.
- Всі напрямки зберігаються всередині `reports` одного документа.
- 2–3 оновлення Google-звітів за день перезаписують показники цього дня.
- Графік не дублює той самий день у різні години.
