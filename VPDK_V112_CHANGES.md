# VPDK Bonus v112 — технічні зміни

## Backend

- `_transaction_scores()` виключає транзакції магазину з конкурентного рейтингу.
- `_store_spending_by_user()` повертає історичні витрати магазину для відновлення all-time рейтингу поверх поточного балансу.
- Нові store-транзакції мають `meta.source: store`, `prize_id` та `order_id`.
- `CUBE_TABLE` оновлено до діапазонів 0–15, 16–35, 36–70 та 71–105 для граней 1–4.

## Frontend

- `AppLayout` прибирає глобальну шапку, нижню навігацію та обмеження ширини на маршрутах ігор.
- Bonus Match автоматично вмикає pseudo-fullscreen для кожної відкритої сесії.
- Bonus Match і Sudoku блокують `overflow`, overscroll, wheel і touchmove під час активної гри.
- Sudoku використовує фіксований `100dvh` layout із адаптивним розміром сітки.
- Повідомлення мультизаповнення розташоване під сіткою, а не поверх клітинок.
- Підписи рейтингів пояснюють, що покупки в магазині не знижують результат.
