# VPDK Bonus v112 — встановлення

## Що входить

- покупки призів та аватарів у магазині більше не зменшують особистий і командний рейтинг;
- ігрові витрати, платні кидки Щедрого Куба та адміністративні списання й надалі враховуються;
- нові діапазони Щедрого Куба для граней 1–4;
- панель мультизаповнення VPDK Sudoku винесена за межі сітки;
- Bonus Match і VPDK Sudoku працюють без верхньої шапки та нижньої навігації застосунку;
- активне ігрове поле відкривається у повноекранному viewport-режимі, вертикальне гортання та pull-to-refresh заблоковані;
- Service Worker оновлено до `vpdk-v112`.

## Розгортання

1. Розгорніть **backend** з цього архіву.
2. Розгорніть **frontend та Netlify Functions** з цього архіву.
3. Google Apps Script змінювати не потрібно. Залишається версія v111 або чинна сумісна версія.
4. Після deployment повністю закрийте PWA та відкрийте її повторно.
5. Якщо пристрій продовжує показувати старий інтерфейс, очистьте кеш сайту або перевстановіть PWA.

| Грань | Point |
|---:|---:|
| 1 | 0–15 |
| 2 | 16–35 |
| 3 | 36–70 |
| 4 | 71–105 |
| 5 | 106–175 |
| 6 | 176–1000 |

## Логіка рейтингу

- **День / тиждень / місяць:** сума транзакцій за період мінус усі списання, крім покупок у магазині.
- **Весь час:** поточний баланс плюс всі історичні витрати у магазині.
- Покупки старих версій розпізнаються за описом `Купівля:`; нові покупки також отримують `meta.source = store`.
