# Diamond employee card frames v137

## Принцип

Кругла аватарка й надалі працює через наявну двошарову модель:

```text
avatar_url + avatar_rarity + AvatarFrame
```

v137 додає третій, контекстний шар для картки працівника:

```text
картка, що містить AvatarFrame з rarity=diamond
+ /card-frames/diamond-employee-card-v137.png
```

Для визначення використовується CSS `:has(.avatar-frame--diamond)`. Це означає, що прямокутна рамка пов'язана не з ім'ям, місцем у рейтингу чи конкретною сторінкою, а з фактичним активним алмазним аватаром.

## Безпека взаємодії

Рамка малюється через псевдоелемент з `pointer-events: none`, тому вона не блокує кнопки, переходи, реакції та коментарі. Для користувачів із налаштуванням зменшення руху анімація сяйва вимикається.

## Кеш

- Service Worker: `vpdk-v137`;
- реєстраційний URL: `/service-worker.js?v=137`;
- рамка включена до precache.
