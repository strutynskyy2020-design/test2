# TM6 Bonus v110: виправлення командних Google-звітів

## Що виправлено

- Кредитний і дебетовий рейтинги більше не втрачають `team_id` під час нормалізації рядків.
- Логіни з Google Таблиці зіставляються з користувачами та командами через `goals_login`.
- Backend повертає список учасників разом із командою та аватаром у `/api/goals/report-access`.
- Netlify Function `google-goals` додає командні поля безпосередньо до рядків рейтингу.
- Якщо в PWA залишився старий snapshot без командних полів, frontend доповнює його актуальними даними учасників.
- Для режиму без перегляду інших команд залишено безпечний fallback: gateway уже відфільтровує дозволені логіни, тому звіт не зникає через старий кеш.
- Помилковий текст «додайте таблицю» більше не показується, коли таблиця є, але не налаштоване зіставлення команди.
- Service Worker оновлено до `tm6-v110`.

## Розгортання

1. Розгорніть **backend** з каталогу `backend`.
2. Розгорніть **frontend і Netlify Functions** з цього проєкту.
3. Google Apps Script змінювати не потрібно. Залишається версія v106.
4. У Google Таблиці повторно натискати «Оновити звіти» не обов'язково для самого виправлення. Поточний опублікований snapshot буде зіставлено з командами після оновлення застосунку.
5. На телефоні повністю закрийте PWA та відкрийте її знову. Якщо стара версія не зникла, очистьте кеш сайту або перевстановіть PWA.

## Що перевірити в адмін-панелі

Для кожного оператора:

- `goals_login` має точно відповідати логіну в колонці `Credit` або `Debet` на вкладці `Аркуш2`;
- користувач має бути призначений до потрібної команди, наприклад TM6;
- команда має існувати в розділі «Команди».

Регістр літер не має значення. Наприклад, `Fedun` і `fedun` вважаються тим самим логіном.

- Валідація командного зіставлення v110: успішно.
