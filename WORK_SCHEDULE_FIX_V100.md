# TM6 Bonus V100 — виправлення завантаження графіка

## Причина проблеми

Екран V99 показував однакове повідомлення для трьох різних ситуацій:

1. у профілі не задано `goals_login`;
2. логін не знайдено у вкладці `Schedule`;
3. опублікований Google Apps Script Web App працює зі старою версією й взагалі не повертає поле `schedule`.

Через це неможливо було зрозуміти, чому календар порожній.

## Зміни

- Netlify-функція тепер повертає точну причину помилки графіка.
- Додано резервний пошук за частиною email до символу `@`, якщо `goals_login` не задано.
- Невидимі пробіли та zero-width символи в логінах очищаються перед порівнянням.
- Для адміністратора й редактора додано вибір співробітника на сторінці `/schedule`.
- Вибраний співробітник зберігається локально й використовується у картці графіка на головній.
- Якщо Apps Script deployment застарів, інтерфейс прямо показує інструкцію про нову версію Web App.
- Apps Script повертає `api_version: v100`.
- Service Worker cache оновлено до `tm6-v100`.

## Обов'язковий крок після деплою

1. Замінити код Google Apps Script файлом `integrations/google-sheets/Code.gs`.
2. В Apps Script відкрити **Deploy → Manage deployments → Edit**.
3. У полі **Version** вибрати **New version**.
4. Натиснути **Deploy**.
5. Якщо URL `/exec` змінився, оновити `GOOGLE_GOALS_SCRIPT_URL` у Netlify.
6. Перевикласти Netlify з очищенням кешу.
