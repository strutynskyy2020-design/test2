# VPDK Bonus v143 — встановлення

## База

Версія v143 створена поверх frontend v142.

## Що оновити

Потрібно розгорнути лише **frontend / Netlify** з пакета v143.

Backend залишається без змін. Google Apps Script також без змін.

## Після деплою

1. Повністю закрийте PWA або вкладку застосунку.
2. Відкрийте застосунок повторно.
3. Якщо залишився старий вигляд, виконайте hard refresh.
4. Перевірте алмазний профіль на головній та алмазні події у стрічці активності.

Service Worker має версію `vpdk-v143`.
