# VPDK Bonus v121 — виправлення проекційного депозитного рейтингу

## Причина помилки
Попередній парсер зупинявся на першій клітинці зі словом `Deposit` на аркуші `Аркуш2`. Якщо раніше на аркуші траплявся інший службовий напис `Deposit`, функція читала неправильні колонки та повертала порожні масиви:

- `deposit_projection_leaderboard: []`
- `deposit_projection_group_summaries: {}`

## Що виправлено
- Перевіряються всі блоки з заголовком `Deposit`.
- Для кожного кандидата перевіряється реальна структура даних: команда, логін, відсоток.
- Обирається блок із найбільшою кількістю коректних команд та операторів.
- Підтримуються додаткові службові колонки між командою, логіном і результатом.
- До snapshot додається `deposit_projection_diagnostics` для швидкої діагностики.

## Установлення
1. У Google Apps Script повністю замініть код файлом `VPDK-Code-v121.gs`.
2. Натисніть **Зберегти**.
3. Виберіть функцію `refreshReports` і запустіть її.
4. Після успішного виконання натисніть у таблиці **«Оновити звіти»** або повторно запустіть `refreshReports`.
5. Повністю закрийте PWA і відкрийте знову.

Frontend і backend для цього виправлення передеплоювати не потрібно.
