# VPDK Bonus v140 — встановлення

Версія v140 додає обмежені за кількістю акції на призи та разові повідомлення адміністратора для працівників. Вона побудована поверх v139 і зберігає всі зміни економіки ігор, AI-тренажера, Щедрого куба та адмін-інструментів.

## Що потрібно оновити

1. **Backend** з каталогу `backend`.
2. **Frontend і Netlify Functions** з каталогів `frontend` та `netlify`.
3. Google Apps Script змінювати не потрібно. Залишається `VPDK-Code-v130.gs`.

Нові MongoDB-колекції та індекси створюються автоматично під час запуску backend:

- `prize_promotions`;
- `announcements`;
- `announcement_reads`.

Додаткові змінні середовища не потрібні.

## Порядок розгортання

1. Розгорніть backend v140.
2. Переконайтеся, що endpoint `/api/health` відповідає без помилки.
3. Розгорніть frontend/Netlify v140.
4. Повністю закрийте PWA та відкрийте знову або виконайте `Ctrl + Shift + R`.
5. У Service Worker має використовуватися кеш `vpdk-v140`.

## Як запустити акцію на приз

1. Відкрийте **Адмін-панель → Призи**.
2. Біля потрібного призу натисніть кнопку з відсотком.
3. Вкажіть:
   - знижку в Point;
   - кількість наступних покупок, для яких діє знижка.
4. Натисніть **«Запустити акцію»**.

Приклад: для призу «Довга перерва +30 хв» вказати знижку `200` і кількість `2`. Наступні дві успішні покупки отримають ціну на 200 Point нижчу. Після другої покупки магазин автоматично поверне базову ціну.

Нова акція для того самого призу замінює попередню. Акцію можна завершити вручну з того самого вікна.

## Як опублікувати повідомлення

1. Відкрийте **Адмін-панель → Повідомлення**.
2. Натисніть **«Написати повідомлення»**.
3. Заповніть заголовок і текст.
4. Натисніть **«Опублікувати для всіх»**.

Кожен працівник побачить повідомлення під час першого входу після публікації. Після натискання **«Зрозуміло»** саме це повідомлення для нього більше не з’являється.

Якщо активних непрочитаних повідомлень декілька, вони показуються по одному. Адміністратор може вимкнути повідомлення, відредагувати його або видалити. Редагування не скидає позначки працівників, які вже його закрили. Для повторного показу всім потрібно створити нове повідомлення.

## Перевірки перед передачею

- `python3 -m py_compile backend/server.py`;
- синтаксична JSX-перевірка п’яти змінених frontend-файлів через TypeScript;
- `python3 validate_vpdk_v140.py`;
- `pytest -q tests` — 20 тестів пройдено.

Повну production-збірку npm у контейнері не запускали, оскільки локальні `node_modules` відсутні.
