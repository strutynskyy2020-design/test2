# TM6 BONUS v108 — TM6 Sudoku

## Що додано

- Нова гра **TM6 Sudoku** під Bonus Match на головній сторінці.
- Окремий маршрут `/games/sudoku`.
- Кампанія з 50 перевірених рівнів.
- Класичні, нерегулярні та вертикальні поля.
- 4 режими: Стандарт, Дзен, На час, Без помилок.
- Нотатки, undo/redo, підказки, перевірка, пауза, рестарт.
- Мультизаповнення: затиснути цифру і торкатися кількох клітинок.
- Автозбереження локально та синхронізація з backend.
- Продовження незавершеної гри на іншому пристрої після синхронізації.
- Серверна перевірка правильного розв’язання.
- Нагорода за перше проходження: 5 Point і 10 XP.
- Повторне проходження: 0 Point і 5 XP.
- Service Worker оновлено до `tm6-v108`.

## Розгортання

1. Розгорнути весь проєкт v108, включно з `frontend` і `backend`.
2. Google Apps Script оновлювати не потрібно. Можна залишити v106.
3. Після deployment повністю закрити PWA на телефоні та відкрити знову.
4. Якщо стара версія не зникає, у браузері видалити дані сайту або перевстановити PWA.

## Нові backend-колекції

Створюються автоматично під час startup:

- `sudoku_profiles`
- `sudoku_completions`
- `sudoku_sessions`
- `sudoku_runs`

Ручні міграції MongoDB не потрібні.

## API

- `GET /api/games/sudoku/status`
- `POST /api/games/sudoku/start`
- `PATCH /api/games/sudoku/session`
- `POST /api/games/sudoku/complete`
