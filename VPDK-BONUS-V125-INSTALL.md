# Встановлення VPDK Bonus v125

Версія v125 розділяє операторів на два звітні профілі:

- **Продажник**: чинні звіти за кредитами, дебетом і депозитами.
- **Активатор**: дві окремі сторінки `ПУМБ Online` та `Активація карток`.

## 1. Оновіть застосунок і backend

1. Розпакуйте архів `vpdk-bonus-v125-activation-report-profiles.zip`.
2. Завантажте весь проєкт у репозиторій, з якого виконуються deploy Netlify та backend.
3. Дочекайтеся успішної публікації frontend, Netlify Functions і backend API.
4. Переконайтеся, що frontend використовує оновлену Netlify Function `netlify/functions/google-goals.js`.

Оновлення backend потрібне, бо в профілі користувача з'явилося поле `report_profile`.

## 2. Оновіть Google Apps Script

1. Відкрийте Apps Script, підключений до Google Таблиці `Goals`.
2. Відкрийте основний файл коду.
3. Повністю замініть його вміст кодом із `VPDK-Code-v125.gs`.
4. Збережіть проєкт.
5. Якщо Apps Script працює через версійний web deployment, створіть нову версію deployment зі старими правами доступу.
6. Запустіть функцію `refreshReports` вручну.
7. Підтвердьте дозволи Google, якщо з'явиться запит.

У snapshot має з'явитися версія:

`v125-activation-report-profiles`

## 3. Призначте тип звітів операторам

1. Увійдіть до застосунку як адміністратор.
2. Відкрийте розділ керування користувачами.
3. Відредагуйте кожного оператора TM7, який працює активатором.
4. У полі **«Тип звітів»** виберіть **«Активатор · ПУМБ Online і картки»**.
5. Для продажників залиште **«Продажник · кредити, дебет, депозити»**.
6. Перевірте, що поле `goals_login` користувача точно відповідає логіну в Google Таблиці, наприклад `dzhunuso`, `kamaeva` або `leukhina`.

Старі користувачі без заданого типу автоматично трактуються як продажники. Це захищає чинні звіти TM6, TM7 і TM10 від випадкового перемикання.

## 4. Перезапустіть PWA

1. Повністю закрийте вкладку або встановлений PWA.
2. Відкрийте застосунок знову.
3. Якщо залишилася стара версія, виконайте `Ctrl + Shift + R`.
4. У крайньому разі очистьте дані сайту для домену Netlify та увійдіть повторно.

Service Worker і локальний кеш у цій збірці мають версію `v125`.

## Очікуваний результат

### Для продажника

У вкладці «Цілі» залишаються три поточні напрямки:

- кредитний;
- дебетовий;
- депозитний.

### Для активатора

У вкладці «Цілі» показуються рівно дві сторінки:

- **ПУМБ Online**: проекційний результат, показники місяця та вчора, видачі й командний рейтинг;
- **Активація карток**: місячна проекція, показники місяця та вчора, видачі карток і сегменти **A, B, C, D**.

Продажні звіти для звичайного активатора приховані. Активаційні сторінки для звичайного продажника також закриті. Адміністратор, редактор і керівник команди можуть відкривати обидва типи звітів для контролю команди.
