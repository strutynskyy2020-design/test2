# VPDK Bonus v140 — акції на призи та повідомлення адміністратора

## 1. Акції з обмеженою кількістю покупок

Для кожного призу адміністратор може створити одну активну акцію з двома параметрами:

- `discount_points` — знижка в Point;
- `quantity_total` — кількість наступних успішних покупок.

Поточний залишок зберігається у `quantity_remaining`. Магазин повертає одночасно базову та фактичну ціну:

```text
price                 базова ціна
effective_price       ціна з активною знижкою
promotion_discount    розмір знижки
promotion_quantity_remaining
promotion_active
```

### Захист від одночасних покупок

Акційна одиниця резервується атомарним `find_one_and_update` із перевіркою `quantity_remaining > 0`. Завдяки цьому останню знижку не можуть одночасно використати двоє працівників.

Frontend передає `expected_price`. Якщо поки користувач підтверджував покупку остання акційна одиниця закінчилася, backend повертає `409`, магазин оновлює каталог і просить підтвердити нову ціну. Баланс, склад і лічильник акції мають rollback у разі невдалої покупки.

В історії замовлення зберігаються:

- фактично списана ціна;
- базова ціна;
- розмір знижки;
- ідентифікатор акції.

Для командного призу повідомлення про акцію отримує лише відповідна команда. Для загального призу повідомлення отримують усі працівники.

## 2. Разові повідомлення адміністратора

Адміністратор створює повідомлення з заголовком і текстом. Воно зберігається в `announcements` та відображається глобальним компонентом `AdminAnnouncementModal` поверх будь-якої звичайної сторінки застосунку.

Після закриття backend записує у `announcement_reads` пару:

```text
announcement_id + user_id
```

На цю пару створено унікальний індекс. Тому повідомлення закривається окремо для кожного працівника і не може випадково продублюватися. Локальна позначка використовується лише як резерв на випадок короткої недоступності backend та також розділена за `user_id`.

Адміністратор не бачить працівницьке модальне вікно. В адмін-панелі відображається кількість працівників, які вже закрили кожне повідомлення.

## 3. Адмін-панель

### Вкладка «Призи»

- кнопка акції біля кожного призу;
- форма знижки й кількості;
- фактична акційна ціна;
- залишок акційних одиниць;
- ручне завершення або заміна акції;
- в замовленнях видно базову ціну, акційну ціну та знижку.

### Вкладка «Повідомлення»

- створення й попередній перегляд;
- активний/вимкнений статус;
- редагування;
- видалення;
- лічильник закриттів.

## 4. Магазин

- картки призів та аватарів показують бейдж акції;
- стара ціна перекреслюється;
- сортування виконується за фактичною ціною;
- у підтвердженні показано знижку та залишок;
- після покупки локальний каталог отримує актуальний залишок без очікування повного перезавантаження.

## 5. Сумісність

- v140 базується на v139;
- Google Apps Script залишається `VPDK-Code-v130.gs`;
- існуючі призи, замовлення та повідомлення не потребують ручної міграції;
- старі замовлення сумісні через необов’язкові поля `base_price`, `discount_points` і `promotion_id`;
- світла та темна теми мають окремі контрастні стилі для нових панелей і модального повідомлення.
