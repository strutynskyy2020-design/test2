# VPDK Bonus v113: світла тема, баланс і магазин

## 1. Аудит світлої теми

Перевірено всі маршрутизовані сторінки:

- Home, Feed, Goals, кредитні та дебетові звіти;
- Leaderboard, Teams, Tasks, Quests, History, Schedule;
- Store, Admin, AI Trainer, Fun;
- Login і Register;
- Bonus Match і Sudoku як окремі повноекранні ігрові теми.

Для неігрових сторінок додано спільну контрастну палітру. Слабкі сірі підписи стали темнішими, а неонові акценти на білому тлі замінені глибшими відтінками бурштинового, фіолетового, бірюзового, зеленого, червоного та синього. Окремо виправлено:

- картки кредитних і дебетових звітів;
- виділення поточного оператора;
- заблоковані досягнення;
- активні фільтри стрічки;
- поля, placeholder-тексти та модальні вікна;
- магазин і підтвердження покупки;
- кольори SVG-іконок і статусних кнопок.

Сильні кольорові кнопки зберігають білий напис, щоб глобальна конвертація світлої теми не створювала темний текст на темному або насиченому фоні.

## 2. Адміністрування Point

API `PATCH /api/admin/users/{user_id}/points` тепер приймає два режими:

```json
{
  "amount": 25,
  "mode": "delta",
  "description": "Премія"
}
```

`delta` додає або списує різницю. Позитивне нарахування зберігає попередню XP-логіку.

```json
{
  "amount": 140,
  "mode": "set",
  "description": "Коригування балансу"
}
```

`set` встановлює точний баланс. Така корекція не додає XP і не спотворює прогрес користувача. У транзакції зберігаються `balance_before`, `balance_after` та `adjustment_mode`.

## 3. Нова структура магазину

Користувацькі категорії скорочено до трьох:

1. Все
2. Привілеї
3. Аватарки

Категорії `merch` і `certificate` відфільтровуються зі storefront. Аватари не дублюються у «Все».

Аватари розкладені в п’ять компактних горизонтальних полиць:

- Базові;
- Покращені;
- Рідкісні;
- Епічні;
- Легендарні.

У кожній картці залишено лише потрібне: аватар, коротка назва, бонуси, ціна і дія. Горизонтальне гортання всередині одного рангу значно скорочує довжину сторінки.

## 4. Сумісність

- Формат наявних призів і замовлень не змінено.
- Наявні аватари, покупки й активний аватар не скидаються.
- Google Apps Script та структура Google-звітів не змінювалися.
- Service Worker має версію `vpdk-v113`.
