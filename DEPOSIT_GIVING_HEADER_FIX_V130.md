# Deposit Giving Header Fix v130

## Причина

`findDepositGivingHeader()` вимагала наявності всіх колонок:

- team
- agent
- inb
- vse
- web
- web_apps
- overall

У реальному аркуші немає `VSE`. Через перевірку `every(column !== -1)` весь блок відхилявся, навіть попри коректні `giving month`, `team`, `Агент`, `Web_apps` і `Загальний підсумок`.

## Зміна

Тепер обов'язкові:

- team
- agent
- overall

Також потрібен хоча б один напрямок із `inb`, `vse`, `web`, `web_apps`. Відсутні напрямки читаються безпечним helper-функціоналом як порожні значення.

## Перевірка

Тестовий макет, що повторює поточну структуру таблиці без `VSE`, успішно повертає:

- TM3: 1 видача;
- TM6: 3 видачі;
- TM7: 6 видач;
- `kalapish`: 4;
- `kubraky`: 1;
- `chornosh`: 1.
