# TM6 Bonus V96 — light-first semantic theme

- Light mode is selected once for all existing and new browser profiles.
- Users may switch to dark mode; their explicit choice persists.
- Dark-mode styling is unchanged.
- Light theme uses #FBFBFC / #FFFFFF / #F7F6FA / #E6E3EF.
- KPI status colours: >=100% #22C55E, 80–99.99% #F4B740, <80% #EF5350.
- Legacy fluorescent green is softened only in light mode.
- Feed/Bonus Match activity uses primary purple #6D3DF5.
- Point remains gold and XP uses violet.
