# Diamond female frame fix v134

## Проблема

Жіночі алмазні аватарки мали відображатися з наданою синьо-фіолетовою квітково-кристалічною рамкою. Для гарантованого оновлення ресурсу рамку винесено у новий versioned-файл, щоб уникнути старого кешу браузера або Service Worker.

## Реалізація

`AvatarFrame.jsx`:

```js
return source.includes("male-diamond-")
  ? "/avatar-frames/diamond-male.png"
  : "/avatar-frames/diamond-female-floral-v134.webp";
```

Таким чином:

- чоловічий портрет отримує темну алмазну рамку;
- будь-який жіночий алмазний портрет отримує точну надану квітково-кристалічну рамку;
- портрети не містять вбудованої рамки;
- вибір рамки залишається автоматичним і недоступним оператору окремо.

## Кеш

- Service Worker: `vpdk-v134`
- URL реєстрації: `/service-worker.js?v=134`
